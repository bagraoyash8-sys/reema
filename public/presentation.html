Slide 02 • Context & Goal

Problem Statement & Project Objectives

Why we built Voyara Travels: tackling fragmentation, hidden pricing, and rigid package limitations in modern OTAs.

Current Industry Challenges
  • Rigid Fixed Tour Packages: Traditional OTAs don't allow travelers to custom tailor activities, stays, and concierge perks day-by-day.
  • Opaque Checkout Pricing: Unexpected tax jumps, service markups, and obscure cancellation policies at final payment.
  • Cluttered & Slow Interfaces: Overwhelming banner clutter and sluggish multi-page reloads hurting user conversions.
Voyara Solution & Objectives
  • 5-Step Custom Itinerary Studio: Choose vibe, stay tier, excursions, and perks with real-time budget computation & 15% discount.
  • Agoda-Grade Room Matrix: Side-by-side comparison of inclusions, square footage, bed sizes, and transparent pricing.
  • Digital QR Voucher Verification: Instant printable PDF travel passes with dynamic scannable QR verification.
💡 Target Outcome: Build an intuitive, zero-latency full-stack application suitable for modern commercial deployment.
Slide 03 • Engineering

System Architecture & Technology Stack

Engineered with modern component-driven frontend and a resilient Node.js file database backend.

Frontend Client Layer

Single Page Application (SPA) architecture with React 18 + TypeScript & Pure HTML5/CSS3/Vanilla JS edition. Fast zero-reload state routing.

React 18 Tailwind CSS TypeScript

Backend REST API Layer

Node.js runtime with Express.js routing engine. Handles hotel querying, coupon validation (`VOYARA20`), and booking transactions.

Node.js Express.js CORS

JSON Database Saver

Lightweight atomic file persistence engine (`data/db.js`). Saves user bookings, custom trip plans, and wishlists to disk without DB setup.

File System (fs) Atomic CRUD JSON Storage
⚙️ Port Configuration: React Client on port 3000 • Node.js Full-Stack on port 5000

Slide 09 • Data & Management

Database Persistence & "My Bookings"

Lightweight JSON database saver engine and live customer booking dashboard.

JSON Database Saver (`data/db.js`)

  • data/bookings.json — All customer reservations & states
  • data/custom_trips.json — Bespoke itinerary packages
  • data/wishlist.json — Saved favorite properties

Zero third-party database dependency. Safe atomic file reads & writes handled by Node.js file system.

Live Reservation Management

  • Status Filters: View All, Active Stays, and Cancelled Trips.
  • 1-Click Free Cancellation: Updates database state from Confirmed to Cancelled in real time.
  • Instant Voucher Re-print: Access and print confirmation passes anytime.
🔄 REST API Synchronization: All mutations synchronize via `POST /api/bookings` and `PUT /api/bookings/:id/cancel`.
