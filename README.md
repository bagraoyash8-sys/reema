# 🌍 Voyara Travels — Premium Hotel Booking & Bespoke Itinerary Platform

Voyara Travels is an enterprise-grade travel reservation web application inspired by Agoda, built with modern UI aesthetics, real-time search, interactive room matrix comparisons, 5-step custom trip planning with live budget calculation, and official digital booking vouchers with dynamic QR codes.

---

## ✨ Key Features
- **Hero Search Engine**: Real-time destination lookup across 8 worldwide hubs with check-in/out date calculations.
- **5-Step Custom Trip Planner**: Bespoke itinerary builder with live dynamic pricing and automatic 15% bundle savings.
- **Agoda-Style Room Matrix**: Side-by-side room comparisons with transparent inclusion lists (Free Breakfast, Free Cancellation).
- **2-Step Frictionless Checkout**: Flexible payments (Card, Pay at Hotel, UPI) and promo coupon engine (`VOYARA20`).
- **Dynamic Digital QR Vouchers**: Scannable QR code generation via `QRCode.js` with dedicated `@media print` support.
- **Multi-Currency Engine**: Live currency switching across USD ($), INR (₹), EUR (€), GBP (£), JPY (¥), AUD (A$), and CAD (C$).

---

## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas-Confetti
- **Build Tool**: Vite
- **Typography**: Google Fonts (Outfit & Inter)

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run development server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.
